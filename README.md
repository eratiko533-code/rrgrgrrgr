# 🎬 CINEMA Booking

Қазақ тіліндегі кино билеттерін онлайн броньдауға арналған адаптивті оқу жобасы. Сайт HTML, CSS және JavaScript арқылы жасалған.

## ✨ Мүмкіндіктері

- Заманауи, қараңғы түсті кино сайтының дизайны
- Телефонға, планшетке және компьютерге бейімделген интерфейс
- Фильмдер тізімі және жанр бойынша сүзгілеу
- Фильм, күн және сеанс таңдау
- Интерактивті орын таңдау схемасы
- Билет санын және жалпы бағаны автоматты есептеу
- Броньды растау туралы хабарлама
- Акциялар, сайт туралы ақпарат және FAQ бөлімдері
- Email жазылу формасының демо-нұсқасы

## 🚀 Жергілікті компьютерде іске қосу

1. Репозиторийді жүктеп алыңыз немесе клонданыз:

   ```bash
   git clone https://github.com/USERNAME/cinema-booking.git
   ```

2. Жоба бумасына өтіңіз:

   ```bash
   cd cinema-booking
   ```

3. `index.html` файлын браузерде ашыңыз.

   Немесе Visual Studio Code ішіндегі **Live Server** кеңейтімін пайдаланыңыз.

## 🌐 GitHub-қа жүктеу

1. GitHub-та жаңа репозиторий ашыңыз, мысалы `cinema-booking`.
2. Осы буманың ішіндегі файлдар мен `css`, `js` бумаларын репозиторийге жүктеңіз.
3. GitHub-та **Settings → Pages** бөліміне өтіңіз.
4. **Build and deployment** бөлімінен `Deploy from a branch` таңдаңыз.
5. Branch ретінде `main`, папка ретінде `/ (root)` таңдап, **Save** басыңыз.
6. Біраз уақыттан кейін GitHub Pages сайт сілтемесін көрсетеді.

> Егер репозиторийіңіз басқа атаумен болса, `git clone` пәрменіндегі URL-ді өз репозиторийіңіздің URL-імен ауыстырыңыз.

## 🧪 Маңызды ескерту

Бұл — алдыңғы жақ интерфейсінің (frontend) демонстрациялық нұсқасы. Бронь браузерде ғана көрсетіледі. Дерекқор, сервер және нақты төлем жүйесі қосылмаған. Орындардың бос/бос еместігі де тұрақты дерекқордан алынбайды.
